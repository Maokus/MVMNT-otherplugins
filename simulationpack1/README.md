# Simulation Pack 1

An SDK 2 MVMNT plugin generated by `create-mvmnt-plugin`.

It contains five deterministic fixed-step examples:

- **Double Pendulum** — a damped two-link pendulum with configurable masses, lengths, gravity, and starting angles.
- **MIDI Spring Ball** — scalar position/velocity state with note-on impulses.
- **MIDI Particle Burst** — copied typed-array state and seeded per-step randomness.
- **Audio Inertia** — fixed-duration raw PCM RMS windows driving inertial state.
- **Bouncy Ball Automation Lab** — two-dimensional collision physics driven by an
  automatable gravity scale, with historical property sampling, a keyframe graph,
  and a host-computed integral over the visible range.

Try seeking backward, jumping directly to a later time, changing the seed, and exporting at
different frame rates. Each element should produce the same frame for the same authored inputs and
target time.

Each element uses one invisible, deterministic bounds object for layout. Animated visuals explicitly
opt out of layout, preventing their motion from shifting the element origin and causing flicker.

```sh
npm install
npm run check
```

Start MVMNT in development mode, then run this command from the plugin directory:

```sh
npm run dev
```

MVMNT must itself be running through `npm run dev`, not a production build. The default dev-plugin
port range is 7741 through 7750; in MVMNT, open **Scene Settings → Developer** and select **Scan**
to discover the selected available port. The initial bundle is installed when the browser connects,
and later successful rebuilds unload and replace it without requiring a version bump. After you
connect, either server can start first and MVMNT reconnects automatically. Valid `plugin.json` edits hot-reload, except changing the plugin
ID requires restarting the plugin dev command. Development bundles are session-only and disappear
five seconds after the dev server stops.

Build a distributable bundle with:

```sh
npm run build
```
